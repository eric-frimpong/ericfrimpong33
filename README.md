### 🖥️ Lab 1 — Windows Server Home Lab

```
┌──────────────────────────────────────────────────────────────────┐
│  OS            Windows Server 2022 (Primary DC + Infra Server)   │
│  HYPERVISOR    Oracle VirtualBox (Latest)                        │
│  TOOLS USED    Server Manager │ AD DS │ DNS │ DHCP │ PowerShell  │
│  DOMAIN        lab.local                                         │
│  FOCUS AREA    Full server build, roles, services & management   │
└──────────────────────────────────────────────────────────────────┘
```

**Objective:** Deploy and manage a complete Windows Server 2022 environment from bare install to a fully operational server with key infrastructure roles — replicating the foundation of any enterprise Windows network.

**What I built & practiced:**

| Task | Description |
| ---- | ----------- |
| ⚙️ **Server Installation & Initial Config** | Clean install of Windows Server 2022, static IP configuration, renamed server, ran Windows Updates before any role deployment |
| 🌐 **DNS Server Role** | Installed and configured DNS Server role, created Forward and Reverse Lookup Zones, added A/PTR records, verified name resolution via `nslookup` |
| 📡 **DHCP Server Role** | Deployed DHCP Server role, created IP scope with exclusions, set lease duration, configured DHCP options (Default Gateway, DNS Server) |
| 🏢 **Active Directory Domain Services** | Installed AD DS, promoted server to Domain Controller, created the domain, configured forest/domain functional levels |
| 👤 **User & Group Management** | Created OUs, user accounts, and security groups in ADUC; set account properties, passwords, and group memberships |
| 💻 **Remote Server Administration** | Enabled and used RDP and Windows Admin Center for remote management — simulating real sysadmin workflows |
| 🔧 **PowerShell Automation** | Bulk-created user accounts (`New-ADUser`), queried AD objects (`Get-ADUser`, `Get-ADComputer`), managed services |
| 📋 **Server Manager & Roles Overview** | Monitored role health, reviewed event logs, managed local services, added/removed features |

**Key outcomes:**
- Built end-to-end confidence deploying Windows Server 2022 in a virtualized environment
- Understand how DNS, DHCP, and AD DS work together as the backbone of a Windows network
- Comfortable with both GUI-based administration and PowerShell for common server tasks
- Produced full lab documentation including IP scheme, role configuration notes, and troubleshooting steps

### 🏢 Lab 2 — Active Directory Lab

```
┌──────────────────────────────────────────────────────────────────┐
│  OS            Windows Server 2019 / 2022 (Domain Controller)    │
│  HYPERVISOR    Oracle VirtualBox (Latest)                        │
│  TOOLS USED    ADUC │ ADAC │ PowerShell (AD Module)              │
│  DOMAINS       computerwiz.com · corp.local                      │
│  FOCUS AREA    OUs · Groups · Users · Password & Account Mgmt    │
└──────────────────────────────────────────────────────────────────┘
```

**Objective:** Build and manage enterprise Active Directory structures across two lab environments — covering everything from initial OU design and group creation to real-world helpdesk tasks like password resets, account unlocks, and offboarding.

**What I built & practiced:**

| Task | Description |
| ---- | ----------- |
| 🏗️ **OU Structure Design** | Designed regional OU hierarchies (USA/Europe/Asia with Computers/Users/Servers sub-OUs) and departmental structures (IT/HR/Finance/Marketing/Sales) with accidental deletion protection |
| 👥 **Security & Distribution Groups** | Created 8+ groups across Global Security, Domain Local, and Distribution types; applied naming conventions (`GRP-`, `DL-`) for instant identification |
| 👤 **Bulk User Creation** | Built and ran PowerShell scripts to provision multiple user accounts simultaneously with proper OU placement, department attributes, and forced password change |
| 🔑 **Password Reset (3 Methods)** | Performed resets via ADUC GUI, Active Directory Administrative Center (ADAC), and PowerShell `Set-ADAccountPassword` |
| 🔓 **Account Lockout & Unlock** | Diagnosed lockout causes using `BadLogonCount` and `LastBadPasswordAttempt`; unlocked via `Unlock-ADAccount` and GUI |
| 🚫 **Account Disable & Offboarding** | Disabled departed employee accounts, moved them to `_DISABLED ACCOUNTS` OU, and verified login denial from client machine |
| ✅ **Client-Side Verification** | Logged into `WIN-CLIENT01` to confirm forced password prompts, successful unlocks, and disabled account errors |

**Key outcomes:**
- Fluent in both GUI and PowerShell approaches for all common AD account management tasks
- Understand the difference between ADUC and ADAC and when to use each
- Practiced real helpdesk ticket scenarios (TKT-2001 through TKT-2003) with proper documentation
- Built a scalable, documented AD structure ready to demonstrate to any IT hiring manager
